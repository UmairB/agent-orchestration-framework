# Roadmap: v1.3 Interactive CLI Hardening

**Created:** 2026-05-09
**Completed:** 2026-05-09
**Status:** Shipped

## Goal

Harden AOF's first-run and interactive CLI experience after live repository testing exposed obsolete catalog/default behavior and rough typed prompts.

## Phases

| Phase | Name | Scope | Status |
|-------|------|-------|--------|
| 16 | Live Repository Hardening | Remove SQLite/default catalog behavior from first-run paths and keep project/global assets explicit. | Complete |
| 17 | Interactive CLI | Replace typed prompt helpers with keyboard-driven prompts and add interactive project/global asset creation. | Complete |

## Delivered

1. Removed the SQLite-backed catalog implementation from active CLI paths.
2. Disabled built-in repo default assets.
3. Made `aof init --codex` create an empty `.aof` workspace.
4. Added explicit disabled-catalog errors for catalog-backed commands.
5. Added `@inquirer/prompts` for checkbox, select, input, and confirm prompts.
6. Added interactive `aof add` for project assets.
7. Added interactive `aof global add` for reusable global assets.
8. Preserved explicit flag-based commands for automation and BDD coverage.

## Verification

- `npm run test:unit`
- `npm test`
- `npm run test:integration:ps`
- Manual empty-repo smoke for `aof init --codex` without SQLite warnings.

## Deferred

- `aof install --interactive` redesign.
- Hosted catalog/registry behavior.
- Additional live-repository hardening beyond the concrete first-run finding.
