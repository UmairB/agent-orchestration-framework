## Delivered Behavior

1. `aof assets ...` owns asset creation, inspection, global refs, rendering, validation, cleanup, and UI launch.
2. `aof packages ...` owns managed package intent, package validation, install execution, and lock replay.
3. `aof project ...` owns inspection, validation, diagnostics, and migration.
4. `aof init` remains the only top-level product command and creates source config only.
5. Removed commands fail with replacement guidance and no side effects.
6. Normal apply output is user-facing and concise; technical metadata is reserved for verbose/JSON paths.
7. Generated runtime folders receive `.gitignore` rules to keep generated output out of normal git noise.
8. Skills and commands support flat additional files and `{{files.<name>}}` runtime path placeholders.

## Deferred Scope

- Command frontmatter metadata such as `argument-hint` and `allowed-tools` needs a first-class model.
- Hosted catalog/distribution remains future scope.
- UI execution of apply/install remains future scope.
- Runtime expansion beyond Claude Code and Codex remains future scope.

## Audit Result

No critical blockers remain. v1.4 is ready to merge to trunk.
