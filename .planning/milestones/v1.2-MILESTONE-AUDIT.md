v1.2 passes milestone audit. ## Cross-Phase Integration

- Global source storage stays separate from project `.aof` and app data.
- Project configs own only references to global assets, not copied global source files.
- Project validation only fails for referenced malformed/missing globals; unrelated global drafts do not block local validation.
- Rendered outputs record whether they came from project-local or global source.
- Runtime overrides on global assets are applied during rendering.
- Associated helper files stay explicit, asset-relative, and protected by validation and lock ownership.
- Setup UI exposes Project and Global scopes explicitly and keeps referenced global resources read-only in Project scope.
- Node and Windows PowerShell BDD runners now execute the same global asset and setup UI API scenarios.

## Deferred Scope

The following remain outside v1.2 and should be considered for future milestones:

- Hosted asset package discovery or publishing.
- Cross-machine synchronization of `~/.aof`.
- Vendoring global assets into project `.aof` as explicit snapshots.
- Semantic version pinning and upgrade workflows for global references.
- Runtime support beyond Claude Code and Codex.
- UI-driven execution of init/apply/install.

## Audit Result

No critical blockers remain. v1.2 is ready to archive.
