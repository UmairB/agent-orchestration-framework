## Cross-Phase Integration

- Project initialization stays empty unless the user explicitly creates project or global assets.
- Global assets remain under `~/.aof`; project assets remain under project `.aof`.
- Direct command forms such as `aof add skill code-review --codex` still support automation.
- Deterministic `AOF_TEST_*` prompt inputs keep BDD and CI non-interactive.
- Catalog storage remains disabled until there is a current product path for it.
