## Delivered Behavior

1. Command assets are Claude-only; Codex command targets fail validation/apply preflight with clear guidance.
2. Simple assets cannot configure or imply arguments.
3. Workflows are first-class top-level assets rendered to `.claude/aof/workflows/*.md` and `.codex/aof/workflows/*.md`.
4. Claude command wrappers and Codex skill wrappers can share workflow assets while preserving runtime-specific argument presentation.
5. `{{skills.<id>}}` and `{{workflows.<id>}}` placeholders expand to generated runtime paths and reject missing or runtime-incompatible references.
6. Referenced global skills/workflows participate in reference resolution without copying global source files into project `.aof/`.
7. Setup UI supports Simple vs Workflow-backed authoring, hides arguments in simple mode, disables unsupported runtime choices, and inserts known reference placeholders.
