# Requirements: AOF v1.3 Interactive CLI Hardening

**Defined:** 2026-05-09
**Milestone:** v1.3 Interactive CLI Hardening

## Requirements

### Empty First Run

- [x] **INIT-01**: `aof init --codex` creates an empty project `.aof` workspace without seeded repo defaults.
- [x] **INIT-02**: AOF does not initialize SQLite or emit experimental SQLite warnings on first run.
- [x] **INIT-03**: Catalog-backed commands fail with explicit disabled-catalog guidance while catalog storage is not part of the active product path.

### Interactive CLI

- [x] **ICLI-01**: Runtime selection uses keyboard-driven checkbox prompts when runtime flags are omitted.
- [x] **ICLI-02**: Prompt helpers preserve deterministic environment-driven inputs for tests and automation.
- [x] **ICLI-03**: `aof add` can create project skills, commands, agents, and rules interactively.
- [x] **ICLI-04**: `aof global add` can create global skills, agents, and rules interactively.
- [x] **ICLI-05**: Direct flag-based command forms remain available for non-interactive automation.
- [x] **ICLI-06**: Non-interactive terminals receive clear errors when required prompt input cannot be collected.

### Verification

- [x] **TEST-01**: Unit tests cover prompt parsing and disabled catalog behavior.
- [x] **TEST-02**: Node BDD integration covers empty init and interactive asset creation behavior.
- [x] **TEST-03**: Windows PowerShell BDD integration covers the same user-facing lifecycle behavior.

## Deferred

- `aof install --interactive` remains pending redesign and should be handled in a future milestone.
- Hosted catalog/registry behavior remains disabled until a real product path is selected.
- Additional live repository hardening remains future work when new live-repo findings appear.
