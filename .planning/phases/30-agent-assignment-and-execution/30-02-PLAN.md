# Plan 30-02: CLI And API Surface

## Goal

Expose assignment and execution controls through the existing board CLI and setup UI API.

## Tasks

1. Add `aof boards agents [--json]`.
2. Add `aof boards task assign <board-id> <task-id> <agent-id> [--provider gsd] [--json]`.
3. Add `aof boards execution show <board-id> <task-id> [--json]`.
4. Add `aof boards execution update <board-id> <task-id> --status <status> [--message text] [--handoff text] [--json]`.
5. Add setup UI endpoints for listing agents, assigning tasks, reading execution, and updating execution state.
6. Keep command output terse and scriptable.

## Acceptance Criteria

- CLI users can list configured agents.
- CLI users can assign a phase-linked task to a configured agent.
- CLI users can inspect execution state and logs.
- CLI users can mark execution as waiting, blocked, failed, or complete.
- Setup UI consumers can perform the same operations through JSON APIs.

## Verification

- Extend setup UI unit coverage.
- Extend CLI/BDD coverage under board scenarios.
- Run `npm run test:unit` and the focused integration CLI tests.
