# Plan 30-01: Execution State Foundation

## Goal

Add provider-neutral assignment and execution state for board tasks, with GSD as the first provider.

## Tasks

1. Add a board task update helper in `src/boards.mjs`.
2. Include assignment and execution summaries in board index task summaries.
3. Add `src/board-execution.mjs`.
4. Store detailed execution records under `.aof/boards/<board-id>/executions/<task-id>.json`.
5. Validate execution status values and map them to board statuses.
6. Load available agents from `.aof/aof.config.json`.
7. Enforce GSD phase refs before assignment.

## Acceptance Criteria

- Assigning a task records `assignedAgent` and `execution` on the task JSON.
- Detailed execution records include provider, commands, attempts, logs, and resume context.
- Unknown agents are rejected.
- GSD assignments without a task phase ref are rejected.
- Execution status updates keep board task status in sync.
