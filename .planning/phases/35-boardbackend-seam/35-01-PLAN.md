# 35-01 Plan: Backend Registry And GSD Wrapper

## Goal

Create the internal backend registry and move GSD SDK calls behind a strict backend object while preserving Phase 34 behavior.

## Tasks

1. Add `src/backends/gsd-backend.mjs`.
   - Export `gsdBackend`.
   - Wrap `loadGsdState`, `analyzeGsdRoadmap`, and `assertMilestone` from `src/gsd-sdk-adapter.mjs`.
   - Implement `syncBoardFromMilestone` as a typed SDK aggregation helper, not a BOARD.json writer.
   - Set `capabilities` to include `roadmap`, `milestone`, `sync`, and `assignTask`.

2. Add `src/backends/null-backend.mjs`.
   - Export `nullBackend`.
   - Use deterministic no-op/test responses.
   - Keep capabilities intentionally sparse.
   - Add a code comment that it is test-only and not a user workflow provider.

3. Add `src/backends/index.mjs`.
   - Export `BackendUnsupportedError`.
   - Export `supportedBackends()` and `resolveBackend(name)`.
   - Register only `gsd` and `null`.
   - `resolveBackend()` throws `BACKEND_UNSUPPORTED` with supported backend kinds.

## Verification

- Unit test registry resolution and unsupported backend shape.
- Existing GSD board tests must still pass unchanged.
