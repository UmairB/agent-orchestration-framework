# 35-02 Plan: Board Lifecycle Routing

## Goal

Route board create, attach, repair, and sync through backend resolution without changing normal GSD behavior.

## Tasks

1. Update `src/boards.mjs`.
   - Replace direct SDK calls in roadmap analysis and milestone assertion with backend calls.
   - Validate non-empty `executionProvider` via `resolveBackend()`.
   - Preserve existing `gsd` BOARD.json fields and command strings.
   - Keep `binding.status`, `binding.sdkVersion`, and drift behavior unchanged.

2. Preserve structured errors.
   - Let `BackendUnsupportedError` flow through existing CLI/UI `toJSON()` handling.
   - Keep board lifecycle error conversion for `GsdSdkError`.

3. Update validation narrowly.
   - Accept registered providers in `validateBoardShape`.
   - Keep `gsd`-specific validation scoped to `board.executionProvider === "gsd"`.

## Verification

- Existing Phase 34 sync/attach/repair tests remain green.
- Add unsupported provider creation/validation coverage.
