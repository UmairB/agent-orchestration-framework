# Plan 33-01: SDK Dependency And Adapter Boundary

## Goal

Pin `@gsd-build/sdk@0.1.0` exactly and add the single AOF adapter module that owns every SDK import and `gsd-tools.cjs` invocation.

## Tasks

1. Add the exact SDK dependency and lockfile changes.
2. Implement `src/gsd-sdk-adapter.mjs` with `loadGsdState`, `analyzeGsdRoadmap`, `assertMilestone`, `listMilestonePhases`, `gsdSdkVersion`, and `GsdSdkError`.
3. Add a lazy SDK surface probe and a boundary check preventing SDK imports or `gsd-tools.cjs` references outside the adapter.

## Acceptance Criteria

- SDK-01, SDK-02, SDK-03, SDK-04, SDK-05, SDK-06, SDK-08, and SDK-09 are covered.
- `@gsd-build/sdk` is pinned as `"0.1.0"` in `package.json`.
- Only `src/gsd-sdk-adapter.mjs` imports `@gsd-build/sdk`.
- The adapter accepts optional `gsdToolsPath` overrides and otherwise resolves compatible lock-state fields before falling back to the SDK default.
