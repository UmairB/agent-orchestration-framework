# Plan 33-02: Error Wrapping And Dispatch Logging

## Goal

Normalize SDK/tool failures into typed AOF errors and append every adapter tool call to `.aof/cache/boards/dispatch.log.jsonl`.

## Tasks

1. Add `GsdSdkError` with `{code, message, expected?, actual?, next?}` fields.
2. Wrap `GSDToolsError` and unknown failures at the adapter boundary.
3. Record `{ts, command, args, latencyMs, ok}` after every SDK tool call, best-effort.

## Acceptance Criteria

- SDK-07 and DIAG-05 are covered.
- Raw `GSDToolsError` messages do not leak from adapter exports.
- Dispatch log write failure warns to stderr but does not fail the adapter call.
