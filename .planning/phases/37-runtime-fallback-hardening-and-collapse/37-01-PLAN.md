# 37-01 Plan: SDK Phase Runner Adapter

## Goal

Expose typed SDK phase execution through the existing adapter module so board assignment code can call one wrapped AOF function.

## Tasks

1. Extend `src/gsd-sdk-adapter.mjs`.
   - Import `GSD` from `@gsd-build/sdk`.
   - Add `runGsdPhase(projectDir, phaseNumber, options = {})`.
   - Instantiate `new GSD({ projectDir, gsdToolsPath, model?, maxBudgetUsd?, maxTurns? })`.
   - Allow test injection via `options.gsd` or `options.GsdClass`.
   - Wrap thrown SDK failures in `GsdSdkError`.

2. Normalize failed phase/plan results.
   - Add a helper that scans `PhaseRunnerResult.steps[].planResults[]` for failed `PlanResult.error`.
   - Return the typed result unchanged but expose enough failure details for board execution to record `errorSubtype` and messages.
   - If `PhaseRunnerResult.success === false` and no subtype exists, use a stable fallback subtype such as `phase_failed`.

3. Update adapter unit tests and fixture helpers.
   - Add fake `GSD` class coverage for success.
   - Add failed plan result coverage proving subtype/messages are preserved.
   - Add thrown error coverage proving `GsdSdkError` wrapping.

## Verification

- `npm run test:unit`
- `node scripts/check-sdk-boundary.mjs`
