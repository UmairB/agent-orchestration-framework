# 37-03 Plan: Explicit Runtime Fallback

## Goal

Rename and harden the runtime CLI milestone path so it is visibly fallback-only and no longer infers completion from ROADMAP.md mtime.

## Tasks

1. Rename `src/gsd-runtime.mjs`.
   - Move it to `src/gsd-runtime-fallback.mjs`.
   - Update imports in `src/cli.mjs`, `src/setup-ui.mjs`, and tests.
   - Ensure `node scripts/check-sdk-boundary.mjs` still passes.

2. Label fallback invocations.
   - Add a helper that prefixes fallback stderr with `[fallback runtime=<runtime>] SDK path unavailable for <reason>`.
   - Include the label for spawned runtime calls and test-env runtime calls.
   - Preserve existing runtime stdout content.

3. Remove mtime probing.
   - Delete `completedRoadmapPath()` and the `stat` import.
   - After runtime fallback returns, call `loadGsdState()` and use `roadmapPresent` to set `.planning/ROADMAP.md`.
   - If state load fails, keep fallback classification and append a short SDK-state warning to stderr.

4. Improve milestone handoff guidance.
   - Keep unknown `boards milestone` subcommands non-executing.
   - Update help text to point users to `$gsd-new-milestone` followed by `aof boards milestone attach`.
