# 36-03 Plan: v1.6 Migration Fixture And Fingerprint Stability

## Goal

Lock down the v1.6 board upgrade path and make board fingerprints stable across Windows and Linux newline formats.

## Tasks

1. Add canonical migration fixtures.
   - Store `test/fixtures/v1-6-board.json`.
   - Store only task fixture files needed for phase fingerprint matching.
   - Do not store generated board index/cache artifacts.

2. Add BDD migration coverage.
   - Add a happy auto-bind scenario: load v1.6 fixture, run `boards repair`, then `boards sync --milestone`.
   - Add an ambiguous no-guess scenario that proves repair prints manual attach guidance and does not write a guessed milestone id.

3. Add line-ending policy and runtime guard.
   - Add `.gitattributes` entries for `.aof/**/*.json`, `.planning/**/*.md`, `test/fixtures/**`, and `test/integration/**/*.feature`.
   - Normalize board/task fingerprint content before hashing in `src/boards.mjs`.
   - Add a focused unit test proving CRLF and LF canonical board/task content produce the same index fingerprint.
