# 36-02 Plan: SDK BDD And PowerShell Parity

   - Set both `context.gsdSdkFixtureName` and optional JSON overrides.
   - Propagate `AOF_TEST_GSD_SDK_FIXTURE` through child-process and in-process runners.

2. Add SDK-path board scenarios.

3. Patch PowerShell integration runner.
   - Create temp roots containing a space.
   - Support the explicit SDK fixture setup step.
   - Propagate named SDK fixture and JSON override env vars.
   - Support GSD runtime status/output env for existing board scenarios.
