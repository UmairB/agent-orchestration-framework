# 36-01 Plan: Captured Fixture Harness And SDK Contract

## Goal

Create the reusable SDK fixture replay harness and a dedicated SDK contract script without expanding default test requirements.

## Tasks

1. Add `test/support/mock-gsd-tools.mjs`.
   - Export `MockGSDTools`.
   - Load `test/fixtures/gsd-sdk/<scenario>/roadmap-analyze.stdout.json`.
   - Load `test/fixtures/gsd-sdk/<scenario>/state-load.stdout.txt`.
   - Support small object overrides for `milestone`, `milestones`, `phases`, and tool failures.
   - Implement the `GSDTools` prototype surface required by `assertGsdSdkSurface`.
   - Throw on unknown command/arg pairs.

2. Extend `src/gsd-sdk-adapter.mjs`.
   - Recognize `AOF_TEST_GSD_SDK_FIXTURE=<name>`.
   - Preserve `AOF_TEST_GSD_SDK_FIXTURE_JSON`.
   - Merge named captured fixture data with JSON overrides.
   - Keep all fixture behavior behind explicit test env variables.

3. Update adapter unit coverage.
   - Use `MockGSDTools` for injected-tool tests.
   - Add named-env fixture coverage.
   - Assert unknown SDK commands fail strictly.

4. Add `test/integration/sdk-contract.mjs` and package script.
   - Validate the SDK surface probe.
   - Exercise adapter state/roadmap calls against a controlled fixture path.
   - Keep the script callable as `npm run test:integration:sdk-contract`.

## Verification

- `npm run test:unit`
- `npm run test:integration:sdk-contract`
