# Phase 15 Wave 3 Plan: Milestone Audit And Archive

## Objective

Create the final v1.2 verification and milestone audit artifacts, archive the milestone roadmap and requirements snapshots, and update live planning state for the next milestone.

## Planning Assumptions

- Wave 1 coverage matrix is complete.
- Wave 2 verification commands passed or any blocker is documented.
- v1.2 requirements GLIB-01 through TEST-03 can be marked complete only after command evidence and audit artifacts are in place.

## Requirements Covered

- **TEST-01:** Unit coverage is audited and passing.
- **TEST-02:** BDD and UI API coverage is audited and passing.
- **TEST-03:** UI build passes after global asset changes.

## Decisions Covered

- **D-16:** Produce v1.2 milestone audit.
- **D-17:** Archive v1.2 roadmap and requirements snapshots.
- **D-18:** Advance live planning after audit completion.
- **D-19..D-24:** Keep future scope deferred.

## Tasks

1. Write final phase artifacts.
   - Write `.planning/phases/15-global-asset-verification/15-03-SUMMARY.md`.
   - Write `.planning/phases/15-global-asset-verification/15-VERIFICATION.md`.
   - Include coverage matrix result and all required command evidence.

2. Complete requirements and roadmap.
   - Mark `TEST-01`, `TEST-02`, and `TEST-03` complete in `.planning/REQUIREMENTS.md`.
   - Update traceability status and complete count to 22/22.
   - Mark Phase 15 complete in `.planning/ROADMAP.md`.
   - Mark v1.2 shipped if audit passes.

3. Create milestone audit.
   - Write `.planning/milestones/v1.2-MILESTONE-AUDIT.md`.
   - Include shipped behavior, requirement coverage, cross-phase integration flows, automated command evidence, residual risks, deferred scope, and verdict.
   - Explicitly note whether there is any accepted process debt.

4. Archive milestone snapshots.
   - Copy/update current `.planning/ROADMAP.md` into `.planning/milestones/v1.2-ROADMAP.md` after v1.2 completion updates.
   - Copy/update current `.planning/REQUIREMENTS.md` into `.planning/milestones/v1.2-REQUIREMENTS.md`.
   - Update `.planning/MILESTONES.md` with v1.2 shipped status, completion date, archive links, and known deferred items.

5. Update project and state.
   - Move v1.2 global asset behavior into validated state in `.planning/PROJECT.md`.
   - Update `.planning/STATE.md` to indicate v1.2 is complete and the next milestone is not yet planned, unless a next milestone has already been selected.
   - Preserve deferred scope: hosted distribution, cross-machine sync, versioning, vendoring, runtime expansion, and UI execution.

6. Final hygiene.
   - Run `git diff --check`.
   - Ensure no generated build output is staged.
   - Commit Phase 15 closeout changes.
