# Plan 34-01: Typed Binding And SDK-Driven Sync Core

## Goal

Replace markdown roadmap parsing in board sync with adapter-driven typed roadmap analysis, and persist canonical milestone binding state in BOARD.json.

## Tasks

1. Add board-domain helpers in `src/boards.mjs` for:
   - typed board errors with `{code, message, expected?, actual?, next?}`;
   - milestone id normalization and missing-argument handling;
   - SDK phase normalization into `{phaseId, title, goal}`;
   - phase identity fingerprinting from normalized phases;
   - binding object updates with `status`, `sdkVersion`, `fingerprint`, and optional `driftReason`.
2. Rework `syncBoardFromGsdRoadmap` to:
   - require `options.milestoneId`;
   - call `assertMilestone()` and `analyzeGsdRoadmap()` from `src/gsd-sdk-adapter.mjs`;
   - reject missing, mismatched, unknown, and incomplete milestones with structured codes;
   - create missing `phase-*` tasks from normalized SDK phases only;
   - write `gsd.milestone.phases[]` and `gsd.milestone.binding`.
3. Remove `parseRoadmapPhases` and `nextBoldValue` from the sync path entirely.
4. Add dry-run planning for `--dry-run --json` with per-phase `{phaseId, action}` where `action` is `create`, `keep`, or `drift`, and no BOARD/task writes.
5. Ensure re-sync is idempotent: no task rewrites for existing phase tasks, no BOARD write on dry-run, and `binding.status = "synced"` only after all task writes succeed.

## Decision Coverage

- D-01: Missing `--milestone` hard-fails with `MILESTONE_MISSING_ARG` and an exact next command.
- D-02: Sync uses SDK `RoadmapAnalysis` only and removes markdown parsing.
- D-03: SDK analysis failures are typed failures, never fallback triggers.
- D-04: Dry-run JSON reports per-phase `{phaseId, action}` without writes.
- D-05: Re-sync is idempotent and marks synced only after writes succeed.
- D-06: `gsd.milestone.binding.status` becomes the readiness gate.
- D-07: Binding statuses are `pending-attachment`, `attached`, `synced`, `drift`, and `error`.
- D-08: Binding fingerprint hashes normalized `{phaseId, title, goal}` rows only.
- D-09: Partial sync failures persist `binding.status = "error"` with a structured reason.
- D-10: `binding.sdkVersion` is written with binding state.

## Acceptance Criteria

- SYNC-01, SYNC-02, SYNC-03, SYNC-04, SYNC-05, SYNC-06, and SYNC-07 are covered.
- D-01, D-02, D-03, D-04, D-05, D-06, D-07, D-08, D-09, and D-10 are covered by the typed sync and binding work in this plan.
- No sync logic reads `.planning/ROADMAP.md` directly or calls markdown regex helpers.
- `node scripts/check-sdk-boundary.mjs` still passes.
