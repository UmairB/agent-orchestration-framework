# Phase 28 Wave 1 Plan: Board/task Schema And Canonical File Layout

<objective>
Add the shared board/task state module that owns canonical `.aof/boards` files, lifecycle statuses, task history, and archive semantics.
</objective>

<context>
Read before execution:
- `.planning/phases/28-board-and-task-state-foundation/28-CONTEXT.md`
- `.planning/phases/28-board-and-task-state-foundation/28-RESEARCH.md`
- `.planning/REQUIREMENTS.md`
- `src/fs.mjs`
- `src/workspace.mjs`
</context>

<tasks>

1. **Create board state helpers.**
   - Type: code
   - Files: `src/boards.mjs`
   - Action:
     - Define fixed board statuses: `backlog`, `ready`, `in_progress`, `blocked`, `done`.
     - Resolve board paths under `.aof/boards/<board-id>/BOARD.json` and `.aof/boards/<board-id>/tasks/<task-id>.json`.
     - Normalize board and task IDs using existing ID rules.
   - Acceptance criteria:
     - Board paths never escape the project workspace.
     - The module exposes reusable operations for CLI and setup UI callers.

2. **Implement board lifecycle operations.**
   - Type: code
   - Files: `src/boards.mjs`
   - Action:
     - Add `createBoard()`, `listBoards()`, `getBoard()`, and `archiveBoard()`.
     - Store board title, objective/deliverable context, lifecycle columns, active/archived state, and timestamps.
     - Preserve archived board/task files in place.
   - Acceptance criteria:
     - Multiple boards can coexist under `.aof/boards`.
     - Archive does not delete unrelated planning or board files.

3. **Implement task lifecycle operations.**
   - Type: code
   - Files: `src/boards.mjs`
   - Action:
     - Add `addTask()` and `moveTask()`.
     - Store title, description, status, priority, deliverable context, optional `refs`, timestamps, and history.
     - Append history events for creation and status changes.
   - Acceptance criteria:
     - Tasks are created with required metadata and lifecycle status.
     - Status movement is persisted with inspectable history.

4. **Add focused unit coverage.**
   - Type: test
   - Files: `test/boards.test.mjs`, `scripts/test-unit.mjs`
   - Action:
     - Cover board creation/list/show/archive.
     - Cover task add/move and history.
     - Cover invalid IDs and invalid statuses.
   - Acceptance criteria:
     - `npm run test:unit` includes board state tests.

</tasks>

<verification>
- `npm run test:unit`
</verification>
