# Plan 31-01: Board Navigation And Columns

## Goal

Add a project-only board section to the setup UI.

## Tasks

1. Add a Boards entry to the sidebar.
2. Fetch board summaries, board details, agents, and board diagnostics.
3. Display project boards with selection state.
4. Display selected board columns for backlog, ready, in progress, blocked, and done.

## Acceptance Criteria

- Users can reach boards from the setup UI.
- Users can select a board and see tasks grouped by status.
- Diagnostics are visible without leaving the board view.
