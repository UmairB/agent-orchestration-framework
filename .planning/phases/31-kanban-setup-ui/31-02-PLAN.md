# Plan 31-02: Task Editing And Assignment Controls

## Goal

Let users manage board and task state from the setup UI.

## Tasks

1. Add board creation controls.
2. Add task creation controls.
3. Add a task edit API that preserves task history.
4. Add inline task edit controls.
5. Add status movement controls.
6. Add agent assignment controls using configured agents.
7. Add board archive controls.

## Acceptance Criteria

- Users can create boards and tasks.
- Users can edit title, priority, deliverable, and phase refs.
- Users can move, assign, and archive through UI controls.
