# Phase 17 Plan 17-02: Interactive Asset Creation Flow

**Status:** Complete
**Created:** 2026-05-09

## Goal

Define and implement the next interactive CLI slice for explicit project/global asset creation without reintroducing built-in defaults or SQLite-backed catalog behavior.

## Candidate Scope

1. Add an interactive `aof add` wizard for project assets.
2. Add an interactive `aof global add` wizard for reusable global assets.
3. Support kind, id, runtimes, description, and optional file body prompts.
4. Preserve direct flag-based commands for automation.
5. Add BDD coverage for non-interactive fallbacks and prompt test coverage for selection mapping.

## Constraints

- Do not add repo defaults.
- Do not reintroduce SQLite catalog storage.
- Keep project and global assets as the only source models.
- Avoid UI execution scope.

## Verification

- `npm run test:unit`
- `npm test`
- `npm run test:integration:ps` if lifecycle BDD changes

## Result

- Added no-argument `aof add` and `aof global add` interactive asset creation flows.
- Preserved direct `kind id` flag-based command usage for automation.
- Added deterministic resource prompt parsing for BDD and unit coverage.
- Kept repository defaults and SQLite catalog behavior disabled.
