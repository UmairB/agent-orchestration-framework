# 02 · The review renders + hands off, the committed-mock convention, and the bundle lands in source

## User story

As the **operator** driving an ACD UI milestone from build to accept,
I want `refine` to elicit and commit a mock, the DESIGN template to make a binding checklist mandatory,
and `verify`/`continue` to **render the surface, hand the screenshot to the designer, and run QA's
harness** — returning a real verdict or an honest `INCONCLUSIVE` — all shipped from `src/bundle/` so new
aof projects inherit the loop,
so that visual fidelity is verified **without me manually comparing screenshots**, every UI milestone is
born with a readable baseline, and the upgraded loop can never silently regress to living only in
`.claude/` again.

## Tasks

- [x] `tasks/00_refine-elicits-mock.feature` — `refine` elicits mocks from the user; a mock that exists is
  committed under the milestone's `mocks/` dir and referenced in `DESIGN.md` as the conformance source of
  truth (a locally-readable artifact, never a remote-link-only reference); with no mock, the binding
  checklist is mandatory and becomes the source of truth (ADR-003)
- [x] `tasks/01_review-renders-and-judges.feature` — `verify`/`continue` render each DESIGN surface via
  `npx playwright screenshot "<baseUrl|--url><Route>"` at the breakpoints (390/768/1280), **hand the
  screenshot to the designer** to judge and **spawn QA** for the harness/regression/a11y (the ADR-001
  hand-off); a `CONFORMS`/`GAPS`/`INCONCLUSIVE` verdict results, `INCONCLUSIVE` when no render/baseline;
  the orchestration never lets the designer run the browser, and Playwright is invoked on-demand via `npx`
  (not a `package.json` dependency)
- [x] `tasks/02_design-template-baseline.feature` — the bundled `templates/milestone/DESIGN.md` encodes the
  committed-`mocks/` convention as the source of truth AND a mandatory binding-checklist section
  (regions-in-order · components · states · ramp) per surface, and no longer presents a remote-link-only
  mock as the sole reference (ADR-003)
- [x] `tasks/03_conformance-loop-bundled.feature` — the design-conformance contract markers (role split ·
  render→judge hand-off · `CONFORMS`/`GAPS`/`INCONCLUSIVE` · committed-`mocks/`+binding-checklist) are
  present in the **BUNDLED** assets under `src/bundle/` (not only `.claude/`), the NEW drift guard passes,
  and the derived `manifest.json` is regenerated and consistent (ADR-005)

## Notes

Inherits the milestone ADRs (ARCHITECTURE.md). Owns `src/bundle/commands/{refine,verify,continue}.md`,

structural residue (the steps + verdict tokens + npx-not-dep + bundled markers) is @executable.
